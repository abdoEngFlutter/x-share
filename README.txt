X Share 0.9 — جاهز لـ GitHub Pages

فك ضغط XShare-v0.9-Website.zip، ثم ارفع محتوياته مباشرة في جذر مستودع abdoEngFlutter/x-share من Code → Add file → Upload files.
ارفع index.html ومجلد assets وrelease.json وapp-ads.txt، وملف .nojekyll إن ظهر. لا ترفع ملف ZIP نفسه، ولا مجلد GitHub-Pages كغلاف خارجي.
ملفات التثبيت موجودة بالفعل في Releases، ولا يلزم رفع مجلد downloads.

Settings → Pages → Source: Deploy from a branch → main → /(root) → Save.
الرابط المتوقع بعد اكتمال النشر: https://abdoengflutter.github.io/x-share/
لم يتم نشر GitHub Pages من طرفنا أو تغيير إعدادات حساب GitHub.

أزرار Android وWindows تستخدم روابط GitHub Releases الثابتة، ولا تعرض صفحة وسيطة. قد يعرض المتصفح نافذة تأكيد أو اختيار مكان الحفظ.
ملف app-ads.txt لا يغني عن نشر التطبيق بمتجر مدعوم وطلب مراجعة AdMob.
